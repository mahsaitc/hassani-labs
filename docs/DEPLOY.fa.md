# چک‌لیست انتشار Hassani Labs روی هاست

این کارها را هنگام راه‌اندازی سایت روی هاست اصلی انجام دهید. موارد امنیتی و سئوی داخل کد سایت قبلاً انجام شده‌اند (پایین همین صفحه).

## ۱. هاست و دامنه

- گواهی SSL (HTTPS) را فعال کنید. بیشتر هاست‌ها گواهی رایگان Let's Encrypt دارند.
- نسخه PHP را روی 8.2 یا بالاتر بگذارید.
- پشتیبان‌گیری خودکار روزانه هاست را روشن کنید و یک بار بازگردانی را امتحان کنید.

## ۲. فایل wp-config.php روی هاست

این خطوط را بالای خط `/* That's all, stop editing! */` اضافه کنید:

```php
define( 'WP_ENVIRONMENT_TYPE', 'production' );
define( 'WP_DEBUG', false );
define( 'DISALLOW_FILE_EDIT', true );
define( 'FORCE_SSL_ADMIN', true );
define( 'WP_AUTO_UPDATE_CORE', 'minor' );
```

- کلیدهای امنیتی (`AUTH_KEY` و بقیه) را تازه بسازید: https://api.wordpress.org/secret-key/1.1/salt/
- پیشوند جدول‌های پایگاه داده را چیزی غیر از `wp_` بگذارید (هنگام نصب).
- اگر سایت پشت CDN است (مثل ابر آروان یا Cloudflare)، از پشتیبانی هاست بپرسید آی‌پی واقعی بازدیدکننده چطور به وردپرس می‌رسد؛ وگرنه قفل ورود (۵ تلاش اشتباه) برای همه بازدیدکننده‌ها با هم حساب می‌شود.

## ۳. تنظیمات وب‌سرور

روی هاست Apache (cPanel یا DirectAdmin)، در فایل `.htaccess` ریشه سایت:

```apache
Options -Indexes
<FilesMatch "^(wp-config\.php|readme\.html|license\.txt|xmlrpc\.php)$">
	Require all denied
</FilesMatch>
```

و یک فایل `.htaccess` داخل پوشه `wp-content/uploads` تا هیچ فایل PHP در پوشه آپلود اجرا نشود:

```apache
<FilesMatch "\.(php|phtml|phar)$">
	Require all denied
</FilesMatch>
```

روی Nginx (سرور مجازی):

```nginx
autoindex off;
location ~* /(?:uploads|files)/.*\.php$ { deny all; }
location ~* /(wp-config\.php|readme\.html|license\.txt|xmlrpc\.php)$ { deny all; }
```

دسترسی فایل‌ها: پوشه‌ها 755، فایل‌ها 644، و `wp-config.php` روی 600.

## ۴. حساب مدیر

- نام کاربری مدیر نباید `admin` یا ایمیل شما باشد. رمز عبور حداقل ۱۶ نویسه.
- ورود دومرحله‌ای (2FA) را برای حساب مدیر روشن کنید: Wordfence > Login Security.
- در Wordfence، فایروال را روی حالت Extended Protection بگذارید (Wordfence > Firewall > Optimize).
- افزونه‌ها و قالب‌هایی که استفاده نمی‌شوند را حذف کنید (غیرفعال کردن کافی نیست).

## ۵. سئو بعد از انتشار

- تنظیمات > خواندن: تیک «از موتورهای جستجو درخواست شود که این سایت را بررسی نکنند» برداشته باشد.
- سایت را در Google Search Console ثبت کنید و نقشه سایت `/wp-sitemap.xml` را بفرستید. برای Bing Webmaster Tools هم همین کار را بکنید.
- در سفارشی‌سازی > Hassani Labs Options > Social Profiles، نشانی لینکدین، گیت‌هاب، اینستاگرام و دیگر صفحه‌هایتان را وارد کنید. این نشانی‌ها در اطلاعات ساختاریافته (Schema) هم به گوگل معرفی می‌شوند.
- برای هر نوشته و برگه، «چکیده» (Excerpt) را پر کنید؛ همان توضیح زیر عنوان در نتایج گوگل می‌شود.
- با https://search.google.com/test/rich-results یکی دو صفحه را آزمایش کنید.
- با https://pagespeed.web.dev سرعت صفحه اصلی را بسنجید.

## آنچه در کد سایت انجام شده است

امنیت:
- قفل ورود: پس از ۵ رمز اشتباه از یک آی‌پی، ورود برای ۱۵ دقیقه بسته می‌شود (هم صفحه wp-login و هم فرم حساب کاربری فروشگاه).
- XML-RPC خاموش، نسخه وردپرس پنهان (حتی در نشانی فایل‌ها)، فهرست کاربران در REST API و نقشه سایت پنهان، صفحه نویسنده (که نام کاربری را نشان می‌داد) به صفحه «درباره من» می‌رود.
- سربرگ‌های امنیتی؛ روی HTTPS هم HSTS و Content-Security-Policy پایه.
- ویرایش فایل‌ها از پیشخوان بسته است. دیدگاه‌های بازدیدکنندگان پیش از نمایش منتظر تأیید می‌مانند.
- فرم‌های تماس، سفارش و خبرنامه نشانه امنیتی (nonce) و محدودیت تعداد ارسال دارند.

سئو (برای هر دو زبان):
- توضیح متا برای همه صفحه‌ها، نوشته‌ها، محصولات و دسته‌ها (فارسی در /fa/).
- تگ‌های Open Graph و X برای اشتراک‌گذاری در شبکه‌های اجتماعی، با تصویر پیش‌فرض.
- اطلاعات ساختاریافته (JSON-LD): Hassani Labs، شما به‌عنوان بنیان‌گذار، وب‌سایت، مسیر صفحه (Breadcrumb)، نوشته‌های وبلاگ و نرم‌افزار کلینیک.
- noindex برای نسخه آزمایشی Local، نتیجه‌های جستجو، دسته‌های خالی، علاقه‌مندی‌ها و محصولات پنهان.
- hreflang بین فارسی و انگلیسی را Polylang اضافه می‌کند.
